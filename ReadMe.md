# floability-env.cli

This repo is used to capture notebook dependencies using strace and generates a file named `requirements.txt` which includes both manager and worker dependencies. It is required for the notebook to only use a single worker running locally with all worker code in a single function. 


User needs to:

**1.**  Run the following command from the terminal which will launch Jupyter process and open the notebook:

`./floability-env-cli.sh  --notebook {notebook_path} --password {sudo_password}`

**2.**  Annotate worker function with `@worker` command 

**3.**	Run the notebook. 

**4.**	From the terminal, press Ctrl+C to stop the Jupyter process.


<br>

`floability-env.cli` currently does the following: 

**1.**	Adds code to audit the kernel using strace at the top and bottom of the notebook. 

**2.**	Launches Jupyter kernel with the given notebook 

**3.**	Parse the audit logs generated by strace and generates requirements.txt file 

<br>

Acknowledgment: The `floability-env.cli` is built based on the ideas of other existing works [FLINC](https://github.com/depaul-dice/Flinc/) and [Sciunit](https://github.com/depaul-dice/sciunit).
